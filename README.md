# 用户综合管理系统

## 项目简介
基于Java Web的用户管理案例系统，实现用户的增删改查功能。

## 技术栈
- Java Servlet/JSP
- MySQL
- Tomcat

## 功能列表
- 用户查询（按ID）
- 用户新增
- 用户修改
- 用户删除
- 用户列表显示


## 运行说明
1. 导入MySQL数据库（执行user.sql）
2. 修改Dbconn.java中的数据库连接信息
3. 部署到Tomcat服务器
4. 访问index.jsp
